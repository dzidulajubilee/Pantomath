      Deep extraction
      Fetches each new article's full page (not just the RSS teaser) for severity/vendor/threat-actor/IOC detection — RSS summaries are usually too short to contain real indicators. Slower on sources with many new items at once; fails silently back to teaser-only text on paywalls/timeouts. On by default.

      Notifications

      Desktop notifications
      Uses your browser's native notification popup. Requires this tab to stay open — see note below.
      Notify me for
      Minimum severity that triggers a notification
      Browser permission: unknown. Desktop notifications only fire while this dashboard tab is open in your browser, and require a secure connection (HTTPS, or "http://localhost") — browsers silently block the permission prompt on plain HTTP at any other address, with no dialog and no error shown. Pantomath is a web app, not a native app, so there's also no background/OS-level push when the tab is closed.

      Webhooks

      Alert via webhook
      Send a POST request when a new item matches a keyword, a specific source, and/or a minimum severity. Works over plain HTTP — unlike browser notifications, this doesn't need HTTPS.

      Currently stored: —
      Earliest to latest item on disk, and total count
      Reprocess stored items
      Re-runs severity/vendor/threat-actor/IOC detection against everything already on disk, using the current parsing logic — no RSS re-fetch. Use this after an upgrade to backfill data for items stored before a detection feature existed. Can take a while with deep extraction on a large history.
      Backup database
      Downloads the raw SQLite file (/var/lib/pantomath/pantomath.db)
      Restore database
      Replaces ALL current data (items, sources, settings, webhooks) with a previously downloaded backup file. A safety copy of what's currently live is made automatically before the swap.

      Add webhook

      Sends a JSON POST with a "text" summary field (Slack/Discord-compatible) plus full structured data.
      Comma-separated. Matches if ANY keyword appears in the title or summary. Leave blank to match all keywords.
      Skips TLS certificate verification for this webhook (https:// only). Only enable this for endpoints you trust, such as an internal server with a self-signed cert — it removes protection against man-in-the-middle tampering on this connection.
      There's no recovery if this is lost — you'd need to delete and re-add the webhook to reset it.
