      Reprocess stored items

      Runs severity scoring, vendor and threat-actor tagging and indicator extraction again on everything already stored, with the current rules. Nothing is re-fetched. Worth doing after an upgrade that improves detection.

      Backup and restore

      Everything lives in one SQLite file.

      Back up the database

      Downloads the SQLite file (/var/lib/pantomath/pantomath.db) with every item, source, setting and webhook.

      Restore from a backup

      Replaces all current data (items, sources, settings, webhooks) with a backup file. A safety copy of the current database is kept on the server first.

      Security

      Who can change what.

      Settings password

      Needed for Settings, Sources and anything that makes the server fetch a URL. The dashboard, feeds, indicators and analytics stay readable without it, so they work on a shared screen.

      Forgot it? On the server, run sudo pantomath-admin reset-settings-password.

      HTTPS

      Pantomath listens on port 7373 on every network interface. To put it behind nginx with HTTPS, run sudo pantomath-admin setup-https on the server.

      Add webhook

      Sends a JSON POST with a "text" summary field (Slack/Discord-compatible) plus full structured data.
      Comma-separated. Matches if ANY keyword appears in the title or summary. Leave blank to match all keywords.
      Skips TLS certificate verification for this webhook (https:// only). Only enable this for endpoints you trust, such as an internal server with a self-signed cert — it removes protection against man-in-the-middle tampering on this connection.
      There's no recovery if this is lost — you'd need to delete and re-add the webhook to reset it.
